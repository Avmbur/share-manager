# Share Manager

Меню в терминале Ubuntu. Открывает каталог по NFS для Linux и по SMB для Windows: ставит пакеты, записывает клиентов и режим, показывает шары списком.

![Главное меню Share Manager](docs/menu.png)

## Что делает

Скрипт ведёт две службы из одного экрана.

- **NFS** — каталог для Linux. Клиент задаётся IP-адресом, подсетью или `*`.
- **SMB** — каталог для Windows без пароля. В проводнике он открывается как `\\IP-сервера\имя`.
- **Оба протокола** — одна и та же папка сразу для Linux и Windows.

Пакеты ставятся по подтверждению: `nfs-kernel-server` для NFS и `samba` для SMB. Если сервер не принимает новый конфиг, скрипт возвращает файл к тому виду, который был до записи.

Отдельные резервные копии скрипт не хранит.

## Меню

| Пункт | Действие |
| --- | --- |
| 1 | Показать шары NFS и SMB и живой экспорт NFS |
| 2 | Добавить шару: NFS, SMB или оба |
| 3 | Удалить шару целиком |
| 4 | Изменить шару: добавить, убрать или заменить IP, сменить ro/rw, путь и имя для Windows |
| 5 | Проверить конфигурацию (`exportfs -ra` и `testparm`) |
| 6 | Установить или запустить серверы |
| 7 | Разрешить клиенту порты в UFW |
| 8 | Удалить сервер. Настройки можно оставить или очистить |
| 0 | Выход |

В изменении шары клиенты видны списком. Чужие адреса и их опции при правке одного клиента сохраняются. Если у SMB-шары нет ни одного IP, она открыта всей сети. Чтобы снова открыть её всем, удаляется последний адрес.

## Запуск

Нужны Ubuntu с `apt` и `systemd`, а также `bash`. Скрипт проверялся на Ubuntu 26.04.

```bash
sudo bash share-manager.sh
```

Без прав root скрипт вызывает `sudo`. Если пароль не принят, работа на этом заканчивается.

## Запись в каталог

NFS пишет от пользователя `nobody`. Для записи скрипт предлагает сделать его владельцем каталога и поставить режим `755`.

Windows через SMB тоже пишет от `nobody`, но Samba не смотрит на бит владельца. Для SMB нужен режим `775` и группа `nogroup`. Если шара открыта обоими протоколами, скрипт предлагает `775`.

Только чтение этих прав не требует.

## Куда попадают настройки

| Служба | Файл |
| --- | --- |
| NFS | `/etc/exports` |
| SMB, список шар | `/etc/samba/share-manager.conf` |
| SMB, общий вход без пароля | `/etc/samba/smb.conf` |

Для гостевого входа Windows в `smb.conf` записываются `map to guest = Bad User` и `obey pam restrictions = no`. Шары SMB скрипт держит в отдельном файле и подключает его строкой `include`.

Имя SMB-шары: латиница, цифры, точка, `_` и `-`, до 64 символов. Имена `global`, `printers`, `homes`, `ipc$` и `print$` заняты Samba.

Путь к каталогу должен быть абсолютным. Обычный файл и относительный путь скрипт не принимает.

## Сеть

Пункт UFW открывает порты выбранному IP или подсети:

- NFS — `2049` и `111`, TCP и UDP;
- SMB — `445/tcp`.

Звёздочку в адресе UFW и SMB скрипт не берёт. Для NFS `*` по-прежнему означает «все клиенты». Если UFW выключен, правило только записывается и начнёт работать после включения фаервола.

Samba всегда пускает `127.0.0.1`, пока этот адрес прямо не запрещён. Ограничение по IP проверяйте с другой машины, а не с самого сервера.
